# View profile — Module 1.2

Scope: English purple/white mentor profile inspired by the supplied MentorCruise profile layout. Display existing mentor identity, introduction, experience, skills, monthly/one-off prices, and a moderated-review section. Profile navigation must work from homepage and directory, including direct links, back navigation, loading, missing and error states.

This iteration uses the existing prototype catalog, not a database migration. Do not fabricate review comments, service benefits, verification evidence, career history or response-time claims. Missing detail is explicitly empty. Production verified skills and moderated reviews remain dependent on the corresponding data API.

Exclude application forms, checkout, booking, chat, AI summaries, promotions, top-mentor badges and related mentor recommendations.
